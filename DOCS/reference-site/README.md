# Reference site

A working clone of the existing sfdug.org, captured August 2025. It records what
the 2026 rebuild was aiming at — layout, type, colour, and component structure —
and is kept purely as a visual reference.

It lives under `DOCS/` rather than `web/` on purpose: anything inside the docroot
gets served, and a stale copy of the old site reachable at `/HTML/` would be
publicly browsable and search-indexable alongside the real one.

Open `index.html` directly in a browser; it has no build step and no dependency
on the Drupal site around it.
